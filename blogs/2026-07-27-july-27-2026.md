Feature Automatic rotation of regional Cloud SQL database credentials in Secret Manager is available in Preview . This feature lets you automatically generate secure passwords, update target Cloud SQL database instances (PostgreSQL or SQL Server), and rotate secret versions on a configured schedule without custom Cloud Run functions. For more information, see Automatic rotation of Cloud SQL secrets .
